Чеклист проверки чужого teacher.sh (peer-to-peer / 01-edu)
============================================================

Контекст
--------
- Файл для сдачи: teacher.sh
- Скрипт рассчитан на запуск УЖЕ ИЗНУТРИ папки mystery
  (как автотест: cd mystery… && bash teacher.sh)
- MAIN_SUSPECT задаётся снаружи (переменная окружения), не ищется в файлах

Почему "запуск из корня падает" — это НЕ провал
-----------------------------------------------
Если студент запускает из корня репозитория:
  bash teacher.sh
и получает "No such file or directory" для streets/... — это НОРМАЛЬНО.

В корне нет папки streets/ — она лежит в mystery/streets/.
Правильный запуск всегда такой:
  cd mystery
  MAIN_SUSPECT="..." bash ../teacher.sh

Не требуй, чтобы скрипт работал из корня с путями mystery/streets/...
Такой вариант сломает официальный автотест.


ПОДГОТОВКА
----------
[ ] Есть репозиторий с папкой mystery (streets, interviews и т.д.)
[ ] Есть файл teacher.sh проверяемого студента
[ ] teacher.sh лежит рядом с mystery/ (в корне проекта), например:

    project/
      teacher.sh
      mystery/
        streets/
        interviews/


ШАГ 1. Запуск (основной)
------------------------
[ ] Перейти в mystery:
      cd mystery

[ ] Запустить скрипт с переменной:
      MAIN_SUSPECT="Harvey Dent" bash ../teacher.sh


ШАГ 2. Проверить вывод (3 части)
--------------------------------
Вывод должен содержать по порядку:

[ ] 1) Только номер ключевого интервью (цифры), например:
       699607
       (номер может отличаться в других mystery-папках теста,
        но команда поиска одна и та же)

[ ] 2) Текст этого интервью (содержимое файла interviews/interview-НОМЕР)
       Обычно про Annabel Church / синий Honda / L337...

[ ] 3) В конце — ровно значение MAIN_SUSPECT:
       Harvey Dent


ШАГ 3. Проверить, что MAIN_SUSPECT читается снаружи
---------------------------------------------------
[ ] Запустить снова с другим значением:
      MAIN_SUSPECT="The Joker" bash ../teacher.sh

[ ] В конце вывода теперь "The Joker" (не Harvey Dent)
[ ] Номер интервью и текст интервью те же


ШАГ 4. Проверить код глазами (открыть teacher.sh)
-------------------------------------------------
[ ] Номер кладётся в переменную окружения/shell, например INTERVIEWNUMBER=...
[ ] Номер получается командой вроде head | tail (не захардкожен как echo 699607)
[ ] Пути относительно mystery, без префикса mystery/:
      streets/Buckingham_Place
      interviews/interview-...
[ ] Есть вывод переменной с номером (echo $INTERVIEWNUMBER)
[ ] Есть cat интервью по этому номеру
[ ] Есть echo $MAIN_SUSPECT


ШАГ 5. Красные флаги (не засчитывать)
-------------------------------------
[ ] Просто echo готового имени убийцы / захардкоженный номер без head|tail
[ ] Пути mystery/streets/... (сломают автотест)
[ ] Нет вывода MAIN_SUSPECT
[ ] Скрипт падает при правильном запуске из mystery
[ ] Вывод не совпадает по смыслу с шагами 2–3


ИТОГ
----
[ ] Все обязательные пункты шагов 1–4 выполнены → PASS
[ ] Есть красный флаг из шага 5 → FAIL / попросить исправить


Быстрые команды (копипаст)
--------------------------
cd mystery
MAIN_SUSPECT="Harvey Dent" bash ../teacher.sh
MAIN_SUSPECT="The Joker" bash ../teacher.sh

# Если у тебя есть test_teacher.sh под свой teacher.sh —
# для чужого файла временно подставь его путь или скопируй как teacher.sh
